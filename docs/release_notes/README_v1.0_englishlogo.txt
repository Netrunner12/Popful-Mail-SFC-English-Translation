Popful Mail (SFC) - English fan translation - patch v1.0, English title logo edition
====================================================================================

Apply to:  Popful Mail (Japan).sfc   (1 MB, no copier header, CRC32 88E5BCDF)
Result:    2 MB LoROM, CRC32 4A9D8245
Formats:   popful_mail_en_v1.0_englishlogo.bps (recommended, verifies the source ROM)
           popful_mail_en_v1.0_englishlogo.ips (same result, no source check)

This is the v1.0 translation with one difference: the title screen logo
reads "POPFUL MAIL" in English instead of the original Japanese.

- The logo reads "POPFUL MAIL" in pink and purple lettering with the
  sword and star between the words. It uses only the title screen's own
  colours, and plays the original
  zoom-in from the white flash exactly as before. START / CONTINUE and
  the copyright line are unchanged.
- Nothing else differs from the standard v1.0 patch: all text, menus,
  credits and gameplay are identical. Only the title logo's
  own data changes. Saves and the v1.0
  emulator save states work with either edition.

Use either this patch or the standard one, not both: each one applies
to the original Japanese ROM.
